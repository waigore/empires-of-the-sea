# Feature issue template

**Title:** `[Feature] <short capability>`

**Labels:** `todo`, `enhancement`

```markdown
## Summary
<what the user wants>

## Reason
<why it matters — player need, design gap, UX pain>

## Impact analysis
- Pillars touched: <P1–P5 / REQ-* if known>
- Wiki: <already specified | silent | conflicts — link pages>
- Scope guess: <small | medium | large>
- Desktop + mobile: <both | desktop-first | mobile-first | unknown>
- Dependencies / risks: <…>
- Alternatives considered: <… or “none”>

## Proposal
<concrete behavior the issue is asking for>

## Acceptance
- [ ] Behavior playable on desktop and mobile (or explicitly scoped otherwise)
- [ ] Wiki updated if rules change (only after user confirmed follow-up)
```

Optional (only after user confirms wiki follow-up):

```markdown
## Wiki follow-up
- Pages: <wiki page titles/URLs>
- Change needed: <new or revised rule summary>
```
