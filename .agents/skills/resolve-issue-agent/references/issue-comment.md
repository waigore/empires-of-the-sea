# Issue comments (resolve)

Keep comments short. Prefer links over pasting logs.

## When opening / updating a fix PR (still `todo`)

```markdown
Working on this in <PR URL>.
Evidence (WIP): https://github.com/waigore/empires-of-the-sea/wiki/evidence/issue-N
```

## When marking `resolved` (after merge + all tasks done)

```markdown
Resolved via <merged PR URL(s)>.
Evidence: https://github.com/waigore/empires-of-the-sea/wiki/evidence/issue-N
All issue tasks done (code + any wiki follow-ups). Awaiting verification.
```
